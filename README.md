# Pokémon Field Map

지역을 입력하고 **Gotcha!**를 누르면 실제 현재 날씨와 지정한 서식 환경을 바탕으로 포켓몬을 추천하는 비공식 팬 웹앱입니다. HTML, CSS, 브라우저 JavaScript와 Node.js 기본 모듈만 사용합니다. npm 패키지 설치, API 키, `.env` 설정이 필요하지 않습니다.

상단 썸네일은 접속·새로고침할 때마다 등록된 155종 중 하나를 랜덤으로 표시하며, 도감 번호와 이름도 갱신합니다. 브라우저 저장소를 사용할 수 있으면 직전에 표시한 포켓몬을 제외하고 선택합니다. 그림을 불러오지 못하면 기본 썸네일을 유지합니다.

## 실행 순서

1. **Node.js 22 이상**을 설치합니다. 터미널에서 `node --version`으로 확인합니다.
2. PowerShell에서 프로젝트 폴더로 이동합니다.

   ```powershell
   cd "C:\Users\Jeehee\OneDrive\Desktop\personal_pokemon_261013"
   ```

3. 백엔드를 실행합니다. 같은 서버가 프론트엔드 파일도 제공하므로 서버 하나만 실행하면 됩니다.

   ```powershell
   npm start
   ```

   PowerShell에서 npm 실행 정책 오류가 나면 아래 명령을 사용합니다.

   ```powershell
   node --watch backend/server.js
   ```

4. 브라우저에서 **http://localhost:3000**을 엽니다. `index.html`을 직접 더블 클릭해서 열지 마세요.
5. `서울숲`, `해운대`, `한라산` 또는 도시 이름을 입력하고 **Gotcha!**를 누릅니다. 서식 환경을 변경하면 같은 지역에서 다른 환경을 탐험할 수 있습니다. 포켓몬 카드를 누르면 해당 지도 핀이 선택되고 **도감 팝업**이 열립니다. 한국어 도감 설명, 분류, 키·몸무게, 특성(영문), 기본 능력치를 표시합니다. 닫기 버튼, Esc 또는 팝업 바깥 클릭으로 닫을 수 있습니다.
6. 종료하려면 서버 터미널에서 **Ctrl+C**를 누릅니다.

`npm start`는 Node.js의 `--watch` 모드로 실행하므로 백엔드 파일이 변경되면 서버가 자동 재시작됩니다. 이전에 `node backend/server.js`로 실행해 둔 서버는 자동 갱신되지 않습니다. 도감에서 “페이지를 찾지 못했습니다”가 나오면 이전 서버 터미널에서 Ctrl+C를 누르고 `npm start`로 다시 실행한 뒤 브라우저를 새로고침하세요.

지도 포켓몬을 눌러도 도감이 열립니다. 지도 마커는 확대 수준과 무관하게 52px로 표시합니다. 능력치는 HP·공격·방어·스피드·특수방어·특수공격을 육각형 차트로 표시하며, 종족값 기준 각 축의 범위는 0~255입니다. 실제 개체의 레벨·노력치·개체값을 반영한 능력치가 아닙니다.

도감의 **다음 진화**에는 진화할 포켓몬의 그림과 한국어 이름을 표시합니다. 분기 진화는 모든 다음 단계를 보여주며, 더 이상 진화하지 않는 종은 해당 문구를 표시합니다. 진화 조건·지역별 폼은 이 화면에 포함하지 않습니다. 진화 서비스가 실패해도 기본 도감은 표시되고, 도감을 다시 열면 누락된 진화 정보를 재시도합니다.

## 포켓몬 이름으로 탐험지 찾기

화면 맨 아래 작은 검색창에 `피카츄`, `꼬부기`, `이브이`, `리자몽`, `뮤츠` 등을 입력하고 **너로 정했다!**를 누르세요. **1세대 151종 전체와 기존의 부우부·꾸꾸리·갈모매·눈꼬마를 포함한 총 155종**을 검색할 수 있습니다. 검색창의 이름 목록에서도 선택할 수 있습니다. 1세대는 영문 이름(예: `charizard`)으로도 검색할 수 있고, 니드런은 `니드런♀` / `니드런♂` 또는 `니드런 암컷` / `니드런 수컷`으로 구분합니다. 지원하지 않는 이름은 안내 메시지를 표시합니다.

확장 목록의 한국어 이름·타입·서식지 분류는 [PokéAPI 공개 데이터](https://github.com/PokeAPI/pokeapi/tree/master/data/v2/csv)를 로컬 파일 `backend/catalog/kanto.json`에 저장했습니다. 서식지 분류를 앱의 환경(숲·물가·해변·산·도심·초원)에 연결한 규칙과 날씨 특성은 이 앱의 해석입니다. 기존 24종의 생태 설명은 유지합니다. 앱 실행 시 목록을 다운로드하지 않으며, 관리 목적으로 갱신할 때만 `node scripts/update-kanto.mjs`를 실행합니다.

백엔드의 `GET /api/destinations?name=피카츄`는 포켓몬의 서식 환경과 등록된 국내 명소를 비교해 장소와 추천 이유를 반환합니다. 이 추천 자체는 실시간 날씨를 평가하지 않습니다. 추천 장소를 클릭하면 기존 지역 검색으로 연결하여 현재 날씨를 조회하고, 선택한 포켓몬을 지도와 카드에 포함합니다. 명소 추천은 가상의 생태 매칭이며 실제 출현 데이터가 아닙니다. `GET /api/pokemon-catalog`는 검색 가능한 이름 목록을 제공합니다.

3000 포트를 이미 사용하고 있다면:

```powershell
$env:PORT = '3001'
node backend/server.js
```

이때 http://localhost:3001 을 엽니다. 서버는 로컬 컴퓨터의 `127.0.0.1`에서만 수신합니다.

## Vercel 배포

로컬 서버와 Vercel 배포를 모두 지원합니다. Vercel에서는 프론트엔드를 정적으로 제공하고, 루트 `api/index.js`가 기존 백엔드의 요청 처리기를 함수로 실행합니다. `npm start`로 서버를 상시 실행하는 방식이 아닙니다.

1. Vercel에서 이 GitHub 저장소를 연결합니다. 이미 연결했다면 최신 `main` 커밋으로 재배포합니다.
2. **Root Directory는 저장소 루트**로 지정합니다. `frontend` 또는 `backend`를 선택하지 마세요. 루트에 `vercel.json`과 `api/`가 있어야 합니다.
3. 배포 설정은 `vercel.json`에서 지정합니다: **Framework Preset: Other**, **Build Command: npm run build**, **Output Directory: dist**, **Node.js: 22.x**. 환경 변수나 API 키는 필요하지 않습니다.
4. 배포 후 `/`, `/styles.css`, `/app.js`, `/api/pokemon-catalog`가 정상 응답하는지 확인합니다. 이어서 지역 검색·도감·하단 포켓몬 검색을 사용합니다.

Vercel의 홈페이지 `404 NOT_FOUND`는 프론트엔드 출력 경로 또는 프로젝트 설정이 맞지 않을 때 발생할 수 있습니다. 코드 반영 후에도 같은 오류라면 Root Directory, 연결 저장소/Production Branch(`main`), 최신 커밋의 Deployment 상태(`Ready`)를 확인하세요. 이전 배포를 Redeploy하는 경우 이 수정이 포함된 커밋인지 확인해야 합니다.

`npm run build`는 공개할 HTML·CSS·JavaScript 3개만 `dist/`에 복사합니다. `/api/*`는 공통 Vercel 함수로 연결되며 검색 쿼리를 보존합니다. 한국어 포켓몬 목록 JSON은 함수 번들에 포함됩니다. 캐시는 함수 인스턴스별 메모리 캐시라 배포 환경에서 영구 저장되거나 인스턴스 간 공유되지 않습니다.

## 파일 구성

```text
frontend/                 # 브라우저에서 실행
  index.html              # 검색, 지도, 날씨, 추천 카드 화면
  styles.css              # 반응형 디자인
  app.js                  # 백엔드 호출, Leaflet 지도, 카드 상호작용
backend/                  # Node.js에서 실행
  server.js               # HTTP 서버, 지오코딩·날씨 API 호출, 캐시
  locations.js            # 국내 명소 좌표와 서식 환경
  pokemon.js              # 포켓몬 생태 데이터와 추천 규칙
  pokedex.js              # PokéAPI 도감 조회와 메모리 캐시
  destinations.js         # 포켓몬 이름 검색과 서식지별 명소 추천
  catalog/kanto.json       # 1세대 151종 한국어·타입·환경 로컬 데이터
  test/app.test.js         # 규칙 및 HTTP/API 처리 테스트
package.json              # 실행·테스트 명령 (외부 npm 의존성 없음)
api/index.js              # Vercel 함수 진입점
vercel.json               # Vercel 빌드·출력·API 경로 설정
scripts/build.mjs         # 프론트엔드 정적 배포 파일 생성
```

## 동작 방식

1. 프론트엔드가 `GET /api/encounters?region=서울숲&habitat=auto`를 요청합니다.
2. 백엔드는 등록한 명소의 좌표를 사용하거나 **Open-Meteo Geocoding API**로 도시의 좌표를 찾습니다.
3. 백엔드가 **Open-Meteo Weather API**에서 현재 기온, 습도, 강수, 날씨 코드, 풍속, 낮·밤 여부를 가져옵니다. 지역 시간대와 API 기준 시각을 화면에 표시합니다. 이 데이터는 기상 모델에 기반한 현재 조건이며 관측소의 직접 측정값이라고 보장하지 않습니다.
4. 서식 환경에 맞는 포켓몬만 후보로 선정하고, 햇빛·비·뇌우·눈·안개·온도·바람·밤에 맞는 특성을 가산합니다. 비·눈에서는 불꽃 타입, 더위에서는 얼음 타입 점수를 낮춥니다. 최고 6종을 보여줍니다.
5. 좌표별 날씨를 5분간 캐시합니다. 외부 요청은 각각 10초 제한을 두고, 지역 없음·잘못된 입력·외부 서비스 실패를 구분해 안내합니다. 외부 실패 시 가짜 현재 날씨를 만들지 않습니다.

명소 자동 환경: 서울숲(숲), 여의도 한강공원(물가), 해운대·속초해수욕장(해변), 한라산·북한산·남산(산), 경복궁(도심). 별칭은 `backend/locations.js`에서 확인하거나 추가할 수 있습니다.

일반 도시 검색은 검색 API의 첫 번째 결과를 사용합니다. 동명이인은 `Paris, France`처럼 국가를 붙여 구분하고, 화면의 국가·좌표를 확인하세요. 지오코딩은 모든 관광 명소나 거리 주소를 지원하지 않습니다. 검색되지 않는 명소는 인근 도시를 검색하거나 명소 목록에 좌표를 추가하세요. 미등록 지역의 자동 환경은 **도심**이며 실제 토지 이용을 분석하지 않습니다. 환경 선택으로 보정할 수 있습니다.

**적합도는 자체 게임 규칙 점수이며 출현 확률이 아닙니다.** 생태 설명은 포켓몬의 알려진 특징을 바탕으로 요약한 팬 설정이며 날씨 가산 규칙은 이 앱의 해석입니다. 지도에 배치한 포켓몬 핀은 검색 좌표 주변의 가상 표시 위치이며 실제 발견 장소가 아닙니다.

## 외부 서비스와 출처

- [Open-Meteo 날씨](https://open-meteo.com/en/docs), [지오코딩](https://open-meteo.com/en/docs/geocoding-api): API 키 불필요. [무료 사용 정책](https://open-meteo.com/en/pricing)은 비상업용 기준 일 10,000회 제한입니다. 상업용·대규모 사용 시 정책을 확인하세요. 날씨 데이터: CC BY 4.0 / 지역 데이터: GeoNames.
- [Leaflet](https://leafletjs.com/): CDN으로 불러오는 가벼운 지도 라이브러리. 복잡한 프레임워크는 사용하지 않습니다.
- [OpenStreetMap](https://www.openstreetmap.org/copyright): 지도 타일과 출처 표기. 지도는 서비스 정책과 네트워크 상태에 영향을 받습니다.
- [PokéAPI Sprites](https://github.com/PokeAPI/sprites): 포켓몬 그림을 직접 불러옵니다. 이미지 실패 시 이름을 대신 표시합니다.
- [PokéAPI](https://pokeapi.co/docs/v2): 백엔드의 `GET /api/pokemon/:id`가 종별 도감 설명과 기본 데이터를 조회합니다. API 키가 필요 없으며 지원 포켓몬만 조회할 수 있습니다. 한국어 설명을 우선 사용하고 없으면 영문으로 표시하며, 설명의 게임 버전도 함께 표시합니다. 성공 결과는 서버 실행 중 캐시하고, 실패 시 다시 시도할 수 있습니다.
- Google Fonts: 한국어 글꼴. 연결 실패 시 시스템 글꼴을 사용합니다.

인터넷 연결이 필요합니다. 프론트엔드는 날씨 서비스를 직접 호출하지 않고 백엔드만 호출합니다. 지도·이미지는 브라우저가 외부 서버에서 불러옵니다. 지도 라이브러리가 차단되면 추천 결과와 OpenStreetMap 위치 링크를 대신 표시합니다. 날씨 오류가 나면 잠시 후 재시도하고 서버의 외부 HTTPS 접속을 확인하세요.
